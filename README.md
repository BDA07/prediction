# ❤️ Heart Disease Prediction using Neural Networks and Generative AI

## Overview

This project focuses on building a predictive model to detect the likelihood of heart disease using neural networks. We also leverage Generative AI to enhance the quality of training data and improve the model’s performance and generalization.

---

## 🔍 Features

- Predicts presence or absence of heart disease.
- Uses a multi-layer neural network for classification.
- Integrates generative techniques (e.g., synthetic data augmentation).
- Provides evaluation metrics like Accuracy, Precision, Recall, F1-Score.
- Scalable for deployment in healthcare prediction systems.

---

## 📁 Dataset

- **Source**: [UCI Heart Disease Dataset](https://archive.ics.uci.edu/ml/datasets/Heart+Disease)
- Features include age, sex, chest pain type, resting blood pressure, cholesterol, max heart rate, etc.
